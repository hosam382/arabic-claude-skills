وش هي مهارة Claude؟

المهارة (Skill) ملف تعليمات اسمه SKILL.md تحطه في مجلد المهارات عندك. Claude Code يقرأ وصفها القصير، ولما يكون طلبك له علاقة بها يفتحها لحاله ويشتغل بخبرة محددة بدل الكلام العام.

  1. اختر نظام جهازك من تحت.
  2. اضغط «انسخ أمر التثبيت» والصقه في الطرفية (Terminal).
  3. افتح جلسة Claude Code جديدة واطلب عادي، مثل: «دقق هذا النص» أو «اعرض التاريخ بالهجري».
نظام جهازك

قبل ما تثبت: كل مهارة ملف نص عادي، تقدر تقراه كامل من زر «اعرض ملف SKILL.md». الأمر ينزّل هذا الملف بس ويحطه في ~/.claude/skills، وما يشغّل أي برنامج.
صنعها حسام حسين خدا بخش الكود مفتوح على GitHub بُني بمساعدة الذكاء الاصطناعي (Claude) وراجعه حسام.
